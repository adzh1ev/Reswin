# Reswin

Небольшая утилита для управления окнами Windows. Зажмите клавишу-модификатор и используйте мышь: окно можно перемещать за любую точку, менять размер, центрировать, сворачивать и разворачивать.

[Скачать 1.1.4](https://github.com/adzh1ev/Reswin/releases/tag/v1.1.4) · [English](README.md)

## Запуск

Скачайте `Reswin-portable.zip` из [Releases](https://github.com/adzh1ev/Reswin/releases/latest), распакуйте в постоянную папку и откройте `Reswin.exe`. Установка не нужна.

Наведите курсор на окно и зажмите **левый Ctrl**:

| Кнопка мыши | Действие по умолчанию |
| --- | --- |
| Левая, удерживать | Перемещение окна |
| Правая, удерживать | Изменение размера со стороны или угла нажатия |
| Средняя, нажать | Центрирование на текущем мониторе |
| Задняя боковая | Сворачивание |
| Передняя боковая | Разворачивание; повторное нажатие возвращает прежний размер и положение |

Отпустите кнопку или модификатор, чтобы закончить жест. Центрирование учитывает рабочую область монитора и панель задач.

Удерживайте выбранный модификатор и дважды нажмите кнопку мыши, назначенную на **«Перемещение»**, чтобы развернуть окно или вернуть прежний размер. Для привязки перетаскиванием доведите курсор до края нужного монитора и отпустите кнопку мыши: сверху окно развернётся, слева или справа — займёт соответствующую половину рабочей области без предложения выбрать второе окно. Оба жеста включены по умолчанию и отдельно отключаются в верхнем блоке настроек.

Для прокрутки удерживайте **левый Alt** и двигайте мышь вверх или вниз. Чем дальше курсор от начальной точки, тем быстрее прокрутка; отпустите клавишу, чтобы остановить её. Если управление окнами назначено на левый Alt, прокрутка автоматически использует **левый Ctrl**. Чтобы отключить её, выберите «— Без настройки —» в строке «Прокрутка».

## Настройки

Окно разделено на три вкладки: **«Управление»**, **«Чёрный список»** и **«Настройки»**. Активная вкладка выделяется коралловым цветом; при переключении сохраняются назначения и положение списка. Вкладки можно нажимать или выбирать перетаскиванием с зажатой левой кнопкой мыши.

- Выберите левый Ctrl или левый Alt и независимо переназначьте все пять кнопок. Пункт «— Без настройки —» находится в начале списка.
- Независимо включайте и отключайте привязку к краям экрана и разворачивание по двойному нажатию. Жесты используют кнопку мыши, назначенную на «Перемещение».
- Прокрутка автоматически использует другую левую клавишу Ctrl/Alt. В настройке отображается конкретная клавиша; прокрутку можно отключить.
- Ползунок **«Чувствительность»** под прокруткой позволяет выбрать значение от **25% до 200%**. 100% — стандартная чувствительность этой версии. Значение сохраняется между запусками.
- Переключатель **«Включить приложение»** рядом с автозапуском приостанавливает или возобновляет управление окнами и прокрутку.
- Через **Чёрный список → +** добавьте открытую программу в исключения. Все окна этого EXE будут пропускаться. Кнопка **×** удаляет исключение.
- Выберите светлую, тёмную или системную тему, русский или английский язык.
- Включите «Запускать вместе с Windows», если нужен автозапуск в трее. Самостоятельно он не включается.

Настройки сохраняются автоматически в `%LOCALAPPDATA%\Reswin\settings.xml`. Исключения привязаны к полному пути EXE. Если после обновления программы путь изменился, добавьте её заново.

Закрытие и сворачивание настроек прячут окно в трей. Двойной щелчок по значку открывает его снова. В меню трея доступны пауза и полный выход. Повторный запуск открывает уже работающий экземпляр.

`Reswin.exe --tray` запускает приложение сразу в трее. Если перенесли EXE после включения автозапуска, включите его заново из новой папки.

## Требования и ограничения

Windows 10/11 x64 с .NET Framework 4.8 и WPF. Приложение написано на C# с Windows API, без сторонних пакетов, браузерного движка и сетевых запросов.

При перетаскивании развёрнутое окно восстанавливается после небольшого движения мыши. Новые жесты разворачивают только те окна, которые поддерживают разворачивание. Изменение размера и центрирование развёрнутых окон пропускаются. Окна с фиксированным размером не растягиваются. Рабочий стол, панель задач, скрытые и некоторые полноэкранные окна не обрабатываются.

Для управления приложением, запущенным от администратора, Reswin нужны такие же права. Нестандартные рамки, игры и общие процессы-хосты могут требовать доработок. Несколько мониторов с разным масштабом требуют проверки на соответствующем оборудовании.
